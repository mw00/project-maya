# Direct-NH RAM copies: historical four-4090 observations

The opt-in `MAYA_DS4_FLOW_DIRECT_NH=1` path copies each gate/up/down matrix
straight from its registered host-memory parts into the prompt-flow ring. It
avoids assembling those parts in a CPU staging slot first. It applies only to
copied RAM-tier MXFP4 experts in single-member layers with divisible matrix rows;
other items retain their existing path. The setting is off by default. See
[SETTINGS](../SETTINGS.md) for the option.

## Measured version and submission boundary

The measurements below were collected on **2026-10-31 UTC**, using an instrumented
experimental build based on **v1.1.43**, commit
`acdab34bd58eec957715392a1d822777c3c579c3`. All three arms used the same binary
(`25ee3c4baf397a129b3fc5b319ba796f071965c56c397434fe8a88ceb69691fb`),
with direct copies off/on/off. Other experimental paths were disabled.

The submitted minimal implementation is adapted to **v1.1.46**, base
`3589d6f12a3f77e813b184b51a586f8fc3de2185`. It preserves the newer upstream
`flow_copy` diagnostic callers through default arguments and omits the old
measurement instrumentation. **No tests or builds were run for this submission.**
The old measurements do not validate the submitted commit, HIP, Windows, V100,
other formats/topologies, or the upstream CI suite.

## Hardware and protocol

- Four RTX 4090 24 GB cards at 265 W each; two Xeon Platinum 8380 CPUs,
  80 physical cores / 160 threads, two NUMA nodes, about 251 GiB physical RAM.
- Ubuntu 24.04.4, kernel 6.8.0-100-generic, NVIDIA driver 595.99.02.
- `DeepSeek-V4.1-Flash-1017-GSQ-RCO-IQ2_XXS`; context 262144, prompt chunk 8192,
  parallel capacity 8, DSpark on, Engram in RAM, frozen calibration profile.
- A1/B/A2: one shared candidate binary and startup profile, direct-NH disabled /
  enabled / disabled. Each arm made 10 requests: warmup; two fixed, different
  cold inputs at each of 4K/8K/32K; JSON; intentional cancellation; resumption.
  There were **30 candidate requests plus one restoration probe**. Capacity 8
  does not mean these requests were an eight-client load test.
- Performance inputs used greedy generation, reasoning off and 256 output
  tokens; all 18 performance records report zero cached prompt tokens. Ratios
  are computed per matching case as `B / sqrt(A1 * A2) - 1`, then the median
  across the two cases of each length. This is not repeated statistical sampling.

## Recorded results

| Input | Prefill change | Decode change | A2/A1 Decode drift |
| --- | ---: | ---: | ---: |
| 4K | +3.61% | +2.40% | -0.80% |
| 8K | +0.88% | +1.21% | +1.30% |
| 32K | +0.90% | +0.60% | +2.32% |

The 8K/32K prefill observations are small. Decode changes cannot be attributed
to this prompt-copy change from these data alone. There is no general speedup,
significance, p95, concurrency, or default-setting recommendation.

All six performance inputs had matching generated-output hashes across A1/B/A2.
The JSON, warmup and completed resumption outputs also matched. Intentional
cancellation is not a complete-output equality check. The retained run reports
passed JSON/cancel/resume contracts and restoration; hashes do not establish
broad quality or numerical equivalence.

The historical instrumented B build reported positive direct-copy counters on
all four GPUs; A1 reported none. Its **212,240,517,120 bytes are enqueued bytes**,
not measured PCIe bandwidth. Its log also records 17 passing device-format
copy/boundary fixtures. Those instrumentation checks are historical and are
not included or newly executed by this PR.

## Retained evidence

[The JSON export](ds41-direct-nh-v1143-20261031.json) contains all 30 selected
sample records, matching-case summaries, output-equality records, binary/source
fingerprints, sanitized startup arguments, arm settings and request order.
[The compressed inputs](ds41-direct-nh-v1143-20261031-inputs.json.gz) contain the
nine synthetic payloads used by those requests; cancel/resume share a payload.
Payload hashes use the original canonical JSON representation (sorted keys,
compact separators). These are data files, not executable runners.

Paths in the startup template are placeholders. The private calibrated profile
and model pack are not bundled, so the data document this measured configuration
without claiming a turnkey reproduction on a different machine. The historical
arm settings include disabled experiments and diagnostic controls absent from
this minimal patch; only `MAYA_DS4_FLOW_DIRECT_NH` is added by this PR.

# Frozen benchmark prompt corpus

Used by the GLM-5.3 (glm-dsa) speed measurements (`tools/strata/bench_http.py`): the llama.cpp baseline and the engine's own runs.

| File | Nominal tokens | Used for |
|---|---|---|
| `prompt_4k.txt` | 4,096 | decode at 4K context (prompt 4,096 - 256 tokens, then 256 generated) |
| `prompt_8k.txt` | 8,192 | prefill of an 8K prompt |
| `prompt_32k.txt` | 32,768 | decode at 32K context, prefill of a 32K prompt |

Each file holds about 1.6x its nominal token count; `tools/strata/bench_http.py` tokenizes it through the server under test, cuts the exact token count it needs and starts every run at a different offset, so no run reuses a cached prefix.

**Provenance and licence.** The text is generated by `tools/strata/make_bench_corpus.py` from fixed seeds and word lists written for this project; it contains no third-party text. It is dedicated to the public domain (CC0 1.0). `MANIFEST.sha256` freezes the bytes: never edit these files by hand. A change of the corpus invalidates every earlier measurement, so it needs a new corpus directory, not an edit.

Check: `python3 tools/strata/make_bench_corpus.py --check` (also run by `tools/strata/test_bench_http.py`).
